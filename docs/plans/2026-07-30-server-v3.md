# Server V3 implementation plan

## Goal

Deliver an anonymous web-client service with isolated Claude Code contexts/workspaces, configurable models and project Skills, direct device rerun APIs, observable background tasks, and complete downstream documentation.

## Requirements and evidence

- Anonymous paired web client: capability-token context API plus device update API.
- Isolation: token-hash ownership checks, one workspace and Claude session per context, no global listing.
- Claude Code: configurable model/budget/tools, project-only settings, copied `skills/`, sandbox, M5Stack MCP.
- Convenience: deployment plan, direct-run, file upload/list/download, reset, history, cancel.
- Observability: persisted status, stages, progress, heartbeat, silence time, stall flag, replayable SSE.
- Documentation: README, API V3 contract, web integration guide, V2 migration notes.
- Verification: fake Agent integration tests, real device-push mock HTTP test, lifecycle smoke test.
